# Overlord Reigns: final titles (Gnarl-jab pass, APPROVED)

The Archivist's rulings for this pass: titles are **short, pure Gnarl lines**; the jab can aim at **anyone** (the Master, the victims, the minions, the mods); **quest IDs follow the new titles** (`overlord:<chapter>/<snake_case_title>`, apostrophes dropped, `&` = "and", other punctuation removed). Four working titles were kept on purpose: *Peace, What is it good for?*, *The Architect of Chaos*, *We Need a Bigger Sword*, *The Forest's First Keepers*. All 338 Ramblings are retitled too (bottom of this doc).

The working title is the name every spec doc still uses; this doc is the lookup from spec name to the in-game title and ID. The Twine passages should be renamed to the new titles.
